A week of shipped work becomes a written report and a narrated demo video. One config file, one command. The visuals are yours to keep.

This ad was made by newsreel. Every scene is a bundled visual; all three voices ship with it.

The collection

Live cards run the real thing in your browser, paused when off-screen. Prompt-only cards ship the build prompt so you (or your AI) can make your own.

Usage

// a scene in newsreel.config.json
{
  "id": "opener",
  "type": "generated",
  "scene": "swirl",
  "props": { "word": "acme" },
  "duration": 10,
  "narration": "This week we shipped..."
}
// the same visual, in your page
import scene from "./visuals/primitives/swirl.js";

const handle = await scene.mount(el, {
  word: "acme",
  ink: ["#34d399", "#818cf8"],
});
handle.start();
# once, to sign in to your app
npx newsreel login

# capture, cards, voice, music, assemble
npx newsreel run

# what the bundled beds sound like
npx newsreel presets

What you need

node 18+ nodejs.org
playwright peer dep · capture + cards
ffmpeg assembly + audio
voicebox optional · local narration
elevenlabs optional · hosted narration
bundled visuals, music beds, card renderer

Zero runtime dependencies of its own. Playwright is a peer dependency so you control the browser version; ffmpeg comes from your system.
